TypeScript sorrendezési példatár

24 letölthető forrás és importálható v2 modell. A JSON-t az Adatmodell → JSON betöltése, a forrást a Referenciaforrás → Forrásfájl betöltése művelettel nyisd meg. A forrás alkalmazása új modellt generál; az explicit fixed/profil beállítások a JSON-ban vannak.

A beküldött UserAccount program szintaktikailag helyes. Az interface adatmezőinek sorrendje szabad, de a class mezők és this-értékadások megfigyelhető futásidejű sorrendet is adnak. A generátor syntax auditot és korlátozott sorrendelemzést végez, teljes projekt-/típusellenőrzést nem.

A dependencyHints és a sourceLine tájékoztató; a dependencies, edges, profiles, scope és fixed szabályok döntenek. A cím/leírás nem validátorszabály. Az összes generált sor alapból mozgatható; rögzítéshez a JSON fixed mezője kell.
