Feladatok szerkesztése: hozz létre egy új, 1-es séma szerinti JSON fájlt az `examples/` mappában. A Node szerver indításkor validálja a definíciót, az összes referenciakövetelményt, majd egy önellenőrzés keretében a megadott sorrendet is. Hibás referencia esetén megtagadja az indulást. Új feladat betöltése után szerver-újraindítás szükséges. A privát függőségi szabályokat az API nem adja ki.
